# Music

Put background tracks here (`.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`). None are bundled yet.

A track is chosen when its file name contains the story's mood word (for example `tense-01.mp3`
for a "tense" story); otherwise the first file is used. With no files, videos have narration only.

Only add tracks you are allowed to use commercially (CC0 or licensed), and list each one in
`THIRD_PARTY.md` with its source and licence.
